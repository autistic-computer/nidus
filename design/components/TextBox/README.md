# Text box

Shows where the letters sit inside a line box, magnified four times, for any text style.

Inter puts the middle of its capitals at the middle of the line box, so centering a line box centers the text. The bands above the capitals and below the baseline are the space a reader sees on top of any inset: 4.27px each for `body`.

Turn on "ala's default line height" to see text with no style: 13px text on a 21.03px line, which lands between pixels. That is what most native penna text does today.
