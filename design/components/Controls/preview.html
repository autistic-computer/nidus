One anatomy per size

Every control at a size shares its height, text style, inset, icon and icon gap, so a button, a field and a select line up without help. Fields keep a smaller inset because their text starts at the edge.

Density

One setting picks the default control and row height. Text and gaps stay.

Things that sit in a line of text

Keycaps, badges and checkboxes take the line height of the text around them, never a control size, so a line never grows. Shown at twice the size; the stripes are body's 18px lines.
