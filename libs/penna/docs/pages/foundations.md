# Overview

penna is the kit zz and nidus are built from: the controls, the type, the color and the spacing that make both apps feel like one family. The same kit draws native windows and this site, so every picture in these pages is penna itself, not a mock-up.

These pages are for people. They show what penna looks like and explain the thinking behind it. The exact values and rules live in the design spec in the repository, written for the agents that build with the kit.

## Principles

**Keyboard first.** Everything you can click, you can reach from the keyboard, and focus is always visible.

**Quiet chrome.** Bars, sidebars and cards stay calm, so the work inside them is the brightest thing in the window: a terminal, a screen, a document.

**Closer means related.** Space does the grouping. What belongs together sits together, and the eye finds the structure before reading a word.

**One kit, every window.** Native windows and the web draw from the same definitions. Switch a picture to Native to watch ala draw it.

**Themes are looks.** Default, macOS and Yaru are three looks, each in light and dark, and any of them runs on any system. Try the switcher in the corner.
